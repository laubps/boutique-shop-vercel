# Boutique Nova – Sitio Web

**Materia:** Desarrollo de Aplicaciones Web en la Nube y Móviles
**Alumna:** Laura Pelagio

## Descripción

Sitio web estático para una boutique de ropa femenina ubicada en Guadalajara, Jalisco. Construido con HTML5 y CSS3 mediante prompt en Replit con asistencia de IA.

## Tecnologías

- HTML5
- CSS3 (variables, Flexbox, Grid, media queries)
- JavaScript (validación de formulario)

## Secciones

- **Header:** navegación fija con logo y enlaces
- **Hero:** imagen de fondo con texto de bienvenida y llamada a la acción
- **Catálogo:** cuadrícula de 6 productos con imagen, nombre y precio
- **Servicios:** venta de ropa femenina, accesorios y asesoría de imagen
- **Contacto:** formulario con validación de campos requeridos
- **Footer:** datos de la tienda y datos académicos

## Ejecución local

No requiere instalación. Abre `index.html` directamente en el navegador.
